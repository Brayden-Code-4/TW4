# Configure the client and the server

Two sides: the process (`src/server.js` + `.env`) and your script (`TW4_URL`, `TW4_API_KEY`).

## Server (`.env`)

Copy `.env.example`. `npm start` loads the file if the variable is not already in the environment.

| Name | Default | Used for |
| --- | --- | --- |
| `HOST` | `0.0.0.0` | Bind address. Keep `0.0.0.0` in Docker. |
| `PORT` | `3000` | Listen port |
| `API_KEY` | `change-me-now` | Compared to header `X-API-Key` |
| `DATA_FILE` | `./data/tasks.json` | JSON store |
| `LOG_LEVEL` | `info` | `error` / `warn` / `info` / `debug` |
| `NODE_ENV` | `development` | Echoed on `/health` |

Replace the example key with a long random string before you share a machine. Compose reads `API_KEY`, `PORT` and `LOG_LEVEL` from `.env`.

Header name is `X-API-Key`. Node lowercases it to `x-api-key`. Do not send `Authorization: Bearer` — the server ignores it.

## Your app

Suggested names so they do not clash with the server's own `API_KEY` if both run in the same shell:

```bash
export TW4_URL=http://127.0.0.1:3000
export TW4_API_KEY=change-me-now
```

PowerShell:

```powershell
$env:TW4_URL = "http://127.0.0.1:3000"
$env:TW4_API_KEY = "change-me-now"
```

If `API_KEY` is empty on the server, writes return `500` (`server_misconfigured`). That is intentional. The API does not fall back to "open writes".
