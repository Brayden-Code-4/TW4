# Integrate TW4 in an app

TW4 is one HTTP server. Point your code at `http://127.0.0.1:3000` (or whatever `PORT` you set). The helper stay small on purpose: a base URL, a key, `fetch`.

## Node.js 20+

No extra package. Built-in `fetch` is enough.

```js
const BASE = process.env.TW4_URL ?? "http://127.0.0.1:3000";
const KEY = process.env.TW4_API_KEY ?? "change-me-now";

async function createTask(title, status = "todo") {
  const res = await fetch(`${BASE}/api/v1/tasks`, {
    method: "POST",
    headers: {
      "Content-Type": "application/json",
      "X-API-Key": KEY,
    },
    body: JSON.stringify({ title, status }),
  });
  const json = await res.json();
  if (!res.ok) {
    throw new Error(`${res.status} ${json.error}: ${json.message}`);
  }
  return json.data;
}

const task = await createTask("Draft the SDK notes");
console.log(task.id);
```

List:

```js
const res = await fetch(`${BASE}/api/v1/tasks?status=todo`);
const { data, count } = await res.json();
```

## Python 3 (stdlib only)

```python
import json
import os
import urllib.error
import urllib.request

BASE = os.environ.get("TW4_URL", "http://127.0.0.1:3000")
KEY = os.environ.get("TW4_API_KEY", "change-me-now")


def create_task(title, status="todo"):
    req = urllib.request.Request(
        f"{BASE}/api/v1/tasks",
        data=json.dumps({"title": title, "status": status}).encode(),
        headers={
            "Content-Type": "application/json",
            "X-API-Key": KEY,
        },
        method="POST",
    )
    with urllib.request.urlopen(req) as resp:
        return json.load(resp)["data"]


print(create_task("Draft the SDK notes")["id"])
```

`urllib` raises on 4xx. Catch `urllib.error.HTTPError` and read `e.read()` if you want the JSON body.

## Browser

Same `fetch` as Node. Don't put the real `API_KEY` in frontend code you ship to the internet. For a local demo it's fine. For anything public, hide writes behind your own backend.

## Checklist before you wire a client

1. `GET /health` returns `"status":"ok"`
2. Writes send `Content-Type: application/json` **and** `X-API-Key`
3. Task ids in `PATCH` / `DELETE` / `GET /tasks/:id` are full UUIDs (36 chars)
4. You treat 401 as "key", 400 as "your payload", 404 as "id or path"
