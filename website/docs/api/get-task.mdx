# GET /api/v1/tasks/\{id\}

One task. No auth. `{id}` must be a UUID (36 characters).

## Parameters

| Name | In | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | string (UUID) | Yes | Task id from create |

## Response `200`

```json
{
  "data": {
    "id": "78cb84f4-f939-4729-8c7b-2e3fddedd05b",
    "title": "Write the user guide",
    "status": "todo",
    "createdAt": "2026-09-20T17:50:54.691Z",
    "updatedAt": "2026-09-20T17:50:54.691Z"
  }
}
```

## Response `404`

Unknown UUID, or an id that is not a UUID (`/tasks/1`).
