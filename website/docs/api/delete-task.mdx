# DELETE /api/v1/tasks/\{id\}

Remove a task. Needs `X-API-Key`.

## Parameters

| Name | In | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | UUID | Yes | Task id |

## Response `200`

| Field | Type | Description |
| --- | --- | --- |
| `data` | object | The task as it was before delete |
| `deleted` | boolean | Always `true` on success |

## Errors

`401` key, `404` unknown or non-UUID id.

<TabItem value="py" label="Python">

```python
import json, urllib.request

id = "78cb84f4-f939-4729-8c7b-2e3fddedd05b"
req = urllib.request.Request(
    f"http://127.0.0.1:3000/api/v1/tasks/{id}",
    headers={"X-API-Key": "change-me-now"},
    method="DELETE",
)
with urllib.request.urlopen(req) as r:
    print(json.load(r)["deleted"])
```
