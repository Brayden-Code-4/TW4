# PATCH / PUT /api/v1/tasks/\{id\}

Update a task. `PUT` hits the same handler as `PATCH`. Needs `X-API-Key`. Send only the fields you change.

## Parameters

| Name | In | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | UUID | Yes | Task id |
| `title` | body | string | No | New title, not empty if present |
| `status` | body | string | No | `todo`, `doing` or `done` |

## Response `200`

Updated task in `data`. `updatedAt` changes.

## Errors

`400` JSON / validation, `401` key, `404` unknown or non-UUID id.

<TabItem value="py" label="Python">

```python
import json, urllib.request

id = "78cb84f4-f939-4729-8c7b-2e3fddedd05b"
req = urllib.request.Request(
    f"http://127.0.0.1:3000/api/v1/tasks/{id}",
    data=json.dumps({"status": "doing"}).encode(),
    headers={
        "Content-Type": "application/json",
        "X-API-Key": "change-me-now",
    },
    method="PATCH",
)
with urllib.request.urlopen(req) as r:
    print(json.load(r)["data"]["status"])
```
