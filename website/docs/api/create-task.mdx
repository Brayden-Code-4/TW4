# POST /api/v1/tasks

Create a task. Needs `X-API-Key`.

## Headers

| Name | Required | Description |
| --- | --- | --- |
| `Content-Type` | Yes | `application/json` |
| `X-API-Key` | Yes | Same value as `API_KEY` |

## Body

| Name | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `title` | string | Yes | — | Non-empty |
| `status` | string | No | `todo` | `todo`, `doing` or `done` |

## Response `201`

Same task object as GET one, inside `data`. `id` and timestamps are set by the server.

## Errors

`400` bad JSON or validation, `401` key, `500` empty `API_KEY` on the server.

const res = await fetch("http://127.0.0.1:3000/api/v1/tasks", {
  method: "POST",
  headers: {

<TabItem value="py" label="Python">

```python
import json, urllib.request

req = urllib.request.Request(
    "http://127.0.0.1:3000/api/v1/tasks",
    data=json.dumps({
        "title": "Write the architecture overview",
        "status": "todo",
    }).encode(),
    headers={
        "Content-Type": "application/json",
        "X-API-Key": "change-me-now",
    },
    method="POST",
)
with urllib.request.urlopen(req) as r:
    print(json.load(r)["data"]["id"])
```
