# GET /health

Liveness check. No auth.

## Parameters

None.

## Response `200`

| Field | Type | Description |
| --- | --- | --- |
| `status` | string | Always `ok` if the process answered |
| `service` | string | `tw4` |
| `environment` | string | `NODE_ENV` |
| `uptime_seconds` | number | Seconds since start |

```json
{"status":"ok","service":"tw4","environment":"development","uptime_seconds":12}
```
