# TW4 API

This page describes the HTTP API as it is in `src/server.js` today. Base URL on your machine: `http://127.0.0.1:3000`. JSON in, JSON out. Version header on every response: `X-TW4-Version: 1.0.0`. Machine-readable spec: [OpenAPI YAML](/docs/api/openapi).

There is no hosted cloud. You run the process, then you call it.

## What exists

| Method | Path | Auth |
| --- | --- | --- |
| `GET` | [`/health`](/docs/api/health) | No |
| `GET` | [`/api/v1/tasks`](/docs/api/list-tasks) | No |
| `GET` | [`/api/v1/tasks/{id}`](/docs/api/get-task) | No |
| `POST` | [`/api/v1/tasks`](/docs/api/create-task) | `X-API-Key` |
| `PATCH` / `PUT` | [`/api/v1/tasks/{id}`](/docs/api/update-task) | `X-API-Key` |
| `DELETE` | [`/api/v1/tasks/{id}`](/docs/api/delete-task) | `X-API-Key` |

Task object:

| Field | Type | Notes |
| --- | --- | --- |
| `id` | string (UUID) | Set by the server |
| `title` | string | Required on create |
| `status` | string | `todo` \| `doing` \| `done` |
| `createdAt` | string | ISO 8601 |
| `updatedAt` | string | ISO 8601 |

List responses wrap rows in `{ "data": [...], "count": n }`. One task is `{ "data": { ... } }`.

## Auth

See [Authentication](/docs/api/authentication). Reads are open. Writes need the key.

## Errors

See [Status codes](/docs/api/status-codes). Bodies look like `{ "error": "unauthorized", "message": "..." }`.
