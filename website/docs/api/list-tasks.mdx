# GET /api/v1/tasks

List tasks. No auth.

## Parameters

| Name | In | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `status` | query | string | No | `todo`, `doing` or `done` |

## Response `200`

| Field | Type | Description |
| --- | --- | --- |
| `data` | array | Task objects |
| `count` | number | Length of `data` |

```json
{
  "data": [
    {
      "id": "78cb84f4-f939-4729-8c7b-2e3fddedd05b",
      "title": "Write the user guide",
      "status": "todo",
      "createdAt": "2026-09-20T17:50:54.691Z",
      "updatedAt": "2026-09-20T17:50:54.691Z"
    }
  ],
  "count": 1
}
```

## Response `400`

`?status=wip` → `invalid_query`.
